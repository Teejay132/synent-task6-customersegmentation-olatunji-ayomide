# synent-task6-customersegmentation-olatunji-ayomide
# Customer Segmentation using K-Means Clustering

# Problem Statement
Group mall customers based on their behavior using K-Means clustering.

# Dataset
Mall Customer Dataset - sourced from GitHub

# Approach
- Selected Annual Income and Spending Score as clustering features
- Used Elbow Method to find optimal number of clusters (5)
- Applied K-Means clustering with 5 clusters
- Visualized customer segments

# Results
5 distinct customer segments identified ranging from
high income high spenders to low income low spenders
